# 🧳 Travel Planner Agent — 使用说明

> 基于 OpenClaw 智能体的全球旅行规划系统  
> 专攻深度自驾、风光摄影与地道美食的 AI 行程定制

---

## 🖥 页面总览

打开页面后，你会看到一个全屏沉浸式欢迎界面，从上到下分为几个大区：

### 1️⃣ 全球风光轮播大图（顶部）
自动循环播放全球精选风景大片（新西兰暗夜星空、富士山、瑞士瀑布、冰岛冰河湖等），营造沉浸式旅行氛围。

### 2️⃣ 快速输入区（轮播下方核心位置）
输入框 + 两个快速按钮：
- **🇳🇿 新西兰南岛 7 天自驾 / 🇳🇿 NZ South Island 7D**
- **🗼 东京 7 天金秋漫游 / 🗼 Tokyo 7D Autumn**

输入框支持任意目的地，输入后按回车或点击发送按钮即可开始规划。

### 3️⃣ 四引擎知识架构展示（2×2 矩阵卡片）
展示系统背后的四大技术底座：
- **01** — ChromaDB 官方步道与知识底座
- **02** — 联网搜索与实时气象核验
- **03** — OpenClaw 智能体时空规划与节奏编排
- **04** — Bento Grid 多维动态交互呈现层

### 4️⃣ 全球灵感画廊（8 大目的地精选）
点击任意卡片可一键载入该目的地的旅行规划，包含：
- 🇳🇿 新西兰南岛 7 天自驾与暗夜星空
- 🗼 东京 7 天动漫圣地与米其林漫游
- 🇨🇭 瑞士阿尔卑斯 10 天全景列车
- 🇨🇳 贵州 5 天喀斯特瀑布与苗寨秘境
- 还有更多（冰岛极光、新疆伊犁等全球精选）

### 5️⃣ 底部行动区
- **开启旅程** — 聚焦到输入框开始规划
- **直接体验** — 跳过欢迎页直接进入看板

---

## 🚀 开始使用

### 方式 A：输入目的地自由规划（推荐）

在输入框输入你的旅行需求，例如：

```
新西兰南岛 7 天自驾摄影之旅
东京 5 天深度美食游
瑞士 8 天自由行，喜欢雪山和摄影
```

提交后系统会：
1. 显示 **4 阶段 Agent 进度条**（正在构思路线→细化日程→甄选美食摄影→渲染看板）
2. 右侧自动切换到看板视图，展示完整行程

### 方式 B：点击灵感卡片一键规划

在「全球灵感画廊」区点击任意目的地卡片，自动载入该路线进行规划。

### 方式 C：快速按钮

欢迎页输入框下方有两个快速预设按钮，点击即可跳转到对应路线的看板展示。

## 🗓 看板视图功能

提交行程后进入看板模式，包含以下区域：

### 左侧：对话侧栏（Conversational Sidebar）
- 显示对话历史
- 可继续追问/调整行程
- 底部输入框持续对话

### 右侧：行程看板（Dashboard）

#### 🗂 顶部标签导航
| 标签 | 内容 |
|------|------|
| 🏠 **行程总览** | 路线概览、每日总结、照片轮播 |
| 🗓 **详细行程表** | 按天切换，每步有时间、地点、详细描述、交通方式、避坑贴士 |
| 🍜 **必去地标与地道美食** | 图片卡片展示核心景点和特色美食 |
| 📸 **摄影机位指南** | 黄金拍摄时间、构图技巧、镜头参数、穿搭建议 |
| 📋 **完整行程清单** | 沉浸式全览所有信息 |

#### 📅 每日行程卡片（Daily Schedule Card）
每张卡片包含该天的多个活动节点，每个节点有：
- ⏰ 时间
- 📍 地点
- 📝 活动描述
- 🔗 交通方式与避坑贴士

#### 🍽 必去地标与地道美食卡片
图片 + 评分 + 推荐理由，展示核心景点和特色美食（如高山三文鱼、Fergburger 等）。

#### 📷 摄影机位指南卡片
专业级摄影建议，包含：
- 🎯 最佳拍摄时间（日出/日落/蓝调/星空）
- 📐 构图技巧与镜头选择
- ⚙️ 推荐参数（如：14-24mm f/2.8 · 20s · ISO 3200）
- 👗 穿搭与色彩建议

## ⚙️ 技术架构

```
                ┌─────────────────────┐
                │   🌐 前端 (React)    │  Port 5173
                │  Vite + Tailwind    │
                └─────────┬───────────┘
                          │  API 请求
                ┌─────────▼───────────┐
                │   ⚙️ 后端 (FastAPI)  │  Port 8000
                │   Agent Router      │
                └────┬──────┬─────────┘
                     │      │
          ┌──────────▼┐  ┌─▼───────────┐
          │ ChromaDB  │  │ 搜索 & LLM  │
          │ RAG 知识库 │  │ Tavily/Gemini│
          └───────────┘  └─────────────┘
```

### 两种模式

| 模式 | 条件 | 特点 |
|------|------|------|
| **内置引擎** | 不配 API Key | 秒回、无网络依赖、行程合理但较模板化 |
| **LLM 模式** | 配置 API Key | 调用大模型，内容更个性化、更丰富 |

## 📋 运行方式（快速回顾）

```bash
# 终端 1：后端
conda activate travel-agent
cd Travel-planner-agent
python -m backend.main

# 终端 2：前端
cd Travel-planner-agent/frontend
npm install   # 首次需要，后续可跳过
npm run dev
```

浏览器打开 `http://localhost:5173` 🎉
